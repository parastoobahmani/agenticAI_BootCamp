# Sources and attribution

This educational snapshot uses public issue reports from `streamlit/streamlit`,
official Streamlit documentation, release notes and API docstrings. Each usable
record retains its source URL and issue/comment ID or source commit.

The main documentation snapshot uses the exact commit linked in the assignment:
`695e6ce2fb1b23afc6df66b40420ab0013ad72fd`. Three API docstrings come from the
resolved Streamlit `1.50.0` tag; the resolved SHA is in the manifest. The upstream
repository terms apply to upstream materials. Public issue text is attributed
to its original linked report; this project does not claim authorship of it.

Raw API responses containing unnecessary user profile metadata are not included
in the delivery archive. Snapshot cleaning and sampling are described in its
manifest. Designed scenario followups are explicitly labelled and must not be
presented as statements by the original issue reporters.
